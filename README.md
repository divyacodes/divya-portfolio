# Divya P — Portfolio

React 18 + Vite + Tailwind CSS v4 + Framer Motion.

## Run
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/

## Customize
- All content lives in `src/data.js` (links, skills, experience, projects).
- Replace the LinkedIn / GitHub URLs in `src/data.js`.
- Put your resume PDF at `public/resume.pdf` for the Resume button.
- Profile photo: `public/profile.jpg`.

## Deploy (free)
Push to GitHub → import the repo on vercel.com or netlify.com → done.
